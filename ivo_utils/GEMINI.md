# Directrices para el Asistente AI (Antigravity)

1. **PROHIBICIÓN DE SCRIPTS PYTHON**: Bajo ninguna circunstancia debes crear, escribir ni ejecutar archivos o scripts de Python (`.py`) dentro de este workspace para modificar archivos o solucionar problemas.
2. **EDICIÓN MANUAL**: Todos los cambios de código, reparaciones de sintaxis y manipulaciones de archivos deben hacerse directamente sobre los archivos `.lua` utilizando la herramienta de reemplazo de texto (`replace_file_content`) de forma progresiva, o re-escribiendo manualmente el bloque afectado.
3. **PRECISIÓN**: Revisa los archivos poco a poco. No asumas soluciones destructivas ni globales si se puede reparar focalizadamente.
