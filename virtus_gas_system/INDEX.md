# Virtus Gas System
Sistema independiente para la recarga de munición/gas de las armas TFA.

**Módulos Incluidos:**
- **Dispensador (`sw_gas_dispenser`):** Entidad interactiva para que los jugadores recarguen gas.
- **Lógica de Gas:** Sistema que guarda los niveles de gas de cada jugador al morir y los restaura correctamente al reaparecer o ser revividos.
