# Virtus Thirdperson
Sistema aislado que maneja la cámara en tercera persona.

**Módulos Incluidos:**
- Lógica de cliente y servidor para activar la vista en tercera persona.
- **Parche TFA (`sh_virtus_tfa_patch.lua`):** Un parche obligatorio para las armas TFA que previene bugs visuales y asegura que los lásers/tracers se originen correctamente desde el arma cuando la cámara está en tercera persona.
