# IVO AdminSuite
Este addon concentra todas las herramientas de moderación y administración para el Staff.

**Módulos Incluidos:**
- **SAM (`ivosam`):** Sistema base de administración, comandos, base de datos, sistema de tickets, votaciones, sistema de XP y niveles de Defcon. (Nota: Los HUDs de estos sistemas están en `ivo_framework`).
- **Warns (`ivo_warns`):** Sistema de advertencias a jugadores.
- **Logs (`ivo_logs`):** Sistema de registro de muertes, chat y eventos del servidor.
- **Whitelist (`virtus_whitelist`):** Sistema de control para dar acceso a trabajos/facciones.
- **Physgun de Staff (`staffphysgun`):** Sistema que oculta el rayo de la physgun para los usuarios normales y muestra un modelo personalizado/efectos para los administradores en servicio.
